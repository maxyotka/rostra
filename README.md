# Rostra — система компонентов для админок и корпоративного контура

Версия 0.1.0. Строчный характер, холодный графит, один акцент, плотность как токен.

## Что здесь

| Файл | Что это |
| --- | --- |
| `rostra.css` | Ядро: токены, 4 темы, 3 плотности, классы компонентов `rs-*`. Единственный файл, который подключает потребитель. |
| `rostra.tokens.json` | Источник правды по токенам. Из него генерируются css-переменные и темы клиентов. |
| `Rostra Library.html` | Живая библиотека: токены, компоненты во всех состояниях, переключатели темы и плотности. |
| `Прототип — Клиенты.html` | Кликабельная админка на системе: список с фильтрами и поиском, карточка клиента в drawer, создание с валидацией, смена темы и плотности. |
| `Прототип — Диспетчерская.html` | Второй сценарий: доска заявок со SLA, живые таймеры, перевод по этапам, панель деталей, нагрузка смены, лента событий. |
| `Rostra.html` | Дизайн-документ: три характера, экраны, компоненты данных, схемы. История решений. |

## Подключение

```html
<link rel="stylesheet" href="rostra.css">
<div class="rs" data-theme="light" data-density="medium">
  <button class="rs-btn rs-btn--primary">Сохранить</button>
</div>
```

Тема и плотность — атрибуты на любом контейнере, поэтому в одном приложении может жить светлый рабочий стол и тёмная панель мониторинга.

## Принципы

1. **Плотность — токен, а не переделка.** `data-density` меняет высоту контролов, отступы карточек и padding строк таблицы. Компоненты не знают, в каком режиме их отрисуют.
2. **Один акцент.** Синий 262° работает в кнопке, активном пункте, ссылке и графике. Статусные цвета не участвуют в навигации.
3. **Границы вместо теней.** Тень — только у всплывающих слоёв: тост, диалог, поповер, командная палитра.
4. **Три регистра, у каждого своя работа.** «Заголовок» — заголовки, метки полей, кнопки, статусы. `КАПС` с трекингом 0.07em — только надзаголовок секции (`.rs-eyebrow`), шапка таблицы и код/аббревиатура (`SSO`, `CSV`, `PDF`, `ORG-4182`, `ДГ-2026-114`). Капс в кнопке, заголовке или предложении — ошибка: `.rs-eyebrow--sentence` и `.rs-table--sentence-head` отключают его там, где строка длиннее двух слов.
5. **Один экран.** Админка ведёт себя как приложение: высота равна окну, страница целиком не листается. Скроллится только рабочая область (`.rs-pane`), навигация, шапка, фильтры и пагинация приклеены. Если контент не влезает — это повод убрать лишнее или свернуть в раскрывающийся блок, а не отдать пользователю вертикальную прокрутку. Исключение одно: длинные документы и регламенты (`.rs-md`).
6. **Широкая таблица получает две полосы прокрутки** — над шапкой и под последней строкой (`.rs-xbar`), потому что на 20 строках прокрутка вправо не должна требовать спуска в конец списка. Нативная полоса скрывается.
7. **Числа выравниваются по правому краю** и всегда идут табличными цифрами — колонки не прыгают при обновлении данных.
8. **Фокус видно всегда.** `:focus-visible` даёт кольцо `--rs-ring`; убирать его нельзя.

## Надзаголовки секций
Три варианта, больше не вводим:
- `.rs-eyebrow` — по умолчанию. Капс с трекингом 0.07em плюс волосяная линия до конца блока. Секции страниц и библиотеки.
- `.rs-eyebrow--tick` — акцентная риска 10×2 вместо линии. Внутри карточек и панелей, где линия спорит с границей.
- `.rs-eyebrow--tag` — метка на подложке `--rs-surface-3` плюс линия. Над группой карточек, когда ярлык должен читаться как раздел.

Служебные модификаторы: `--bare` (без линии, для групп в сайдбаре), `--sentence` (без капса, когда надпись длиннее двух слов).

## Контент и тон

- Обращение к пользователю на «вы», без восклицаний и эмодзи.
- Кнопка — глагол в инфинитиве: «Сохранить», «Выставить счёт», «Запросить доступ».
- Ошибка называет причину и следующее действие: «Отчёт не собрался за 30 секунд» + «Повторить».
- Пустое состояние не извиняется, а предлагает выход: «Ничего не найдено» + «Сбросить фильтры».
- Единицы — строчными, коды — капсом: `2 часа назад`, `ORG-4182`, `API 42 мс`.

## Иконки

Phosphor Icons, подключается webfont'ом:

```html
<link rel="stylesheet" href="https://unpkg.com/@phosphor-icons/web@2.1.1/src/regular/style.css">
<link rel="stylesheet" href="https://unpkg.com/@phosphor-icons/web@2.1.1/src/bold/style.css">
<link rel="stylesheet" href="https://unpkg.com/@phosphor-icons/web@2.1.1/src/fill/style.css">

<i class="ph ph-buildings" style="font-size:20px"></i>
```

Три веса из шести, у каждого своя работа: **regular** — интерфейс и навигация; **bold** — галочки, каретки, плюсы, всё мелкое до 16 px; **fill** — статусные точки и иконки состояний. Thin, light и duotone не используем.

Размеры: 16 / 18 / 20 / 22. Цвет всегда `currentColor`, кегль наследуется от `font-size` — иконка сама встаёт в тему. В кнопке иконка на 4–5 px меньше высоты строки текста.

## Состав

Формы: Button, IconButton, Input, Textarea, Select, Checkbox, Radio, Switch, Field.
Данные: Table (+ группировка, раскрытие, зебра), Metric, Meter, Badge, Chip, Pagination, EmptyState, Skeleton.
Слои: Dialog, Drawer, Popover, Tooltip, Toast.
Каркас: AppShell (сворачиваемый сайдбар), Topbar, Tabs, Breadcrumbs, Segmented.
Визуализация: линия с областью, столбцы, стек, донат, спарклайн, Steps, Flow, Markdown.
Планшет 768–1024: `data-viewport="tablet"` — сайдбар в рельс 60 px (`.rs-rail`), таблица `.rs-table--sticky` с залипающей первой колонкой, фильтры под одну кнопку со счётчиком.
Системные состояния: `.rs-state` — 403, 404, 500, обслуживание, первый запуск. Иконка 15 px внутри строки кода, без рамки и подложки; причина в заголовке, два выхода из тупика, техническая строка внизу. На экране первого запуска иконки нет вовсе.
Мобильный контур: `data-density="mobile"` (контрол 44, радиус 16, текст 15) + Card, BottomNav, Sheet, ChipScroller, ActionButton. Таблица на мобильном разбирается на карточки: две ключевые метрики в подвале, остальное — на детальной.
Ввод и данные: Calendar (день и период), Combobox/мультиселект с токенами, Menu, Kbd, CellEdit (правка на месте с состояниями «редактируется» и «не сохранено»), Tree, Dropzone и File, Board (канбан), Timeline (аудит), Alert, Avatar/Stack, KeyValue.
