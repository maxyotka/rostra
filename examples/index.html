Rostra

Live pages built on rostra.css. They render from any static host — locally, serve the repository root with python -m http.server. React loads from a CDN, so they need a network.

Library
Every component: buttons, fields, tables, dialogs, calendar, board, tree, motion. Theme and density switches at the top.
Prototype — Clients
A working registry screen: filters, sorting, drawer, dialog, toasts, all four themes.
Prototype — Dispatch
A request board with SLA timers, a shift feed and live metrics.
